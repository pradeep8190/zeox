> An interactive creative device experience combining fluid wave cloth simulations with rotary dial ergonomics and product showcases.

🔗 **Live Experience**: [https://zeo-x.vercel.app](https://zeo-x.vercel.app)

---

## 🌟 Highlights

- **Fluid Wave Silk Simulation**: Procedural sine wave superposition creating organic silk cloth undulations.
- **Rotary Dial Controls**: Multi-state interactive dial with realistic inertia and snap angles.
- **Hardware Device Showcase**: Clean 3D product renders with interactive angle inspectors.
